# ooo-reply-01

My entry for the make.fun bounty "Funniest One-Line Out-of-Office Reply": a single out-of-office auto-reply that reads like something a real person would actually switch on before going away — and quietly deflates every sender who marks their email "urgent". The program writes that one line to `entry.txt`.

Run it with `node main.ts`; set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` lands.
